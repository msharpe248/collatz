# A factor-complexity obstruction for Collatz itineraries

Collatz proof project — September 5, 2026

## Abstract

We formalize an explicit complexity floor for unbounded shortcut Collatz
orbits. If N+1≤2^K, an unbounded orbit from N has at least 5q+1 distinct
parity factors of length 3q+K, for every natural q. Thus a uniform linear
factor-complexity envelope of slope below 5/3 forces boundedness. Since a
bounded orbit has bounded factor complexity, no natural seed has a Sturmian
parity itinerary in the standard definition p(L)=L+1. The same excludes
Sturmian tails after any finite shift. This is a broader class exclusion in
the main Lean project, not a proof of Collatz or a new mathematical discovery.

## Relation to the literature

Dubickas's Theorem 5 gives a stronger asymptotic lower bound, exceeding
1.70951129 times the factor length for sufficiently large lengths on escaping
Collatz trajectories. Our finite rational bound uses the existing certified
3/5-bit height estimate and the parity congruence theorem. It is a direct
formalization of the same type of argument. The paper also states the standard
complexity definition of Sturmian sequences. See
[Dubickas, *On integer sequences generated by linear maps* (2009)](https://doi.org/10.1017/S0017089508004655),
Theorem 5 and the discussion preceding Corollary 4.

The stronger logarithmic constant is not claimed as a Lean theorem here.
No cited mathematical axiom or nested library module is imported by this
formalization.

## Factors and state congruence

Let x_t=T^t(N), using the shortcut map T(n)=n/2 for even n and
T(n)=(3n+1)/2 for odd n. A length-L parity factor at time t is

    (x_t mod 2, x_(t+1) mod 2, ..., x_(t+L−1) mod 2).

Let p_N(L) count the distinct such factors over every natural starting time.
This is a finite set of binary words, even though starting times are unbounded.
The Lean definition uses functions `Fin L → Fin 2` and a finite-set filter.
It is a mathematical, noncomputable definition, not a terminating search
procedure for an unresolved orbit.

If factors at times a and b are equal, the established parity congruence
implies

    x_a ≡ x_b (mod 2^L).

Consequently, if both values are less than 2^L, factor equality forces state
equality. Distinct small states therefore yield distinct factors.

## An explicit finite-scale floor

The universal height estimate already proved in `Collatz.DefectHeight` is

    x_t < 2^(ceil(3t/5)+K),  provided N+1≤2^K.

Fix q and set L=3q+K. For all times t=0,...,5q the state is less than 2^L.
If these 5q+1 states are distinct, their length-L factors are distinct too:

    5q+1 ≤ p_N(3q+K).

This finite-prefix version is proved directly. An unbounded deterministic
orbit cannot repeat a value, so it satisfies the inequality for every q.
No odd-density, reciprocal-summability, or limiting-correction hypothesis
is used.

## A linear envelope forces boundedness

Suppose natural A,B,C satisfy 3B<5A and, for every L,

    A p_N(L) ≤ B L+C.

Assuming an unbounded orbit, the floor at L=3q+K gives

    A(5q+1) ≤ B(3q+K)+C.

Since 5A−3B≥1, choosing q>BK+C contradicts this. Therefore the orbit is
bounded. In particular, any bound p_N(L)≤L+C valid at every length forces
boundedness. The condition is not asserted for arbitrary Collatz itineraries.
Boundedness alone still allows a hypothetical nontrivial cycle.

## The entire Sturmian complexity class is excluded

If all orbit states are at most H, there are at most H+1 possible states.
Each length-L factor is determined by its starting state, hence

    p_N(L) ≤ H+1  for every L.

Now suppose p_N(L)=L+1 for every L, the standard Sturmian complexity
condition. The additive-linear theorem first gives boundedness. Taking
L=H+1 then yields H+2≤H+1, a contradiction.

Thus no natural seed has a Sturmian parity itinerary in this definition.
Applying the same theorem to T^s(N) excludes a Sturmian tail after every
finite shift s. This conclusion handles bounded and unbounded possibilities
without assuming that all bounded orbits enter the trivial cycle.

### Formalization boundary

The new theorem is expressed in the factor-complexity definition. It does
not import or port the equivalence with irrational mechanical rotation words
`mech alpha rho` used by earlier slope-specific modules. Therefore it is not
reported as a new Lean theorem quantified over `alpha` and `rho`. Transporting
the mechanical coding to this complexity framework is a separate remaining
formalization task. The earlier explicit slope/intercept theorems remain valid.
