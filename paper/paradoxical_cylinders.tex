\begin{abstract}
We formalize an exact quotient-interval characterization of paradoxical shortcut Collatz segments. It permits exhaustive enumeration at each fixed length without a seed-height cutoff. Lean proves the complete length-eight classification above seed two. A separate exact-integer Python enumeration through length twenty reproduces the same five segments. A suffix-correction bound now prunes whole prefix subtrees. Tested searches at selected lengths through forty complete with substantially fewer nodes than full residue enumeration. This remains a fixed-length research instrument, not a proof of global finiteness or Collatz.
\end{abstract}
\section{Definition and quotient interval}
Let $T(n)=n/2$ for even $n$ and $(3n+1)/2$ for odd $n$. Let $j_L(n)$ count odd steps before time $L$. Following Rozier and Terracol~\cite{RT}, a segment is paradoxical when
\[
n>0,\qquad T^L(n)\ge n,\qquad 3^{j_L(n)}<2^L.
\]
Intermediate descent is allowed. For a fixed residue $0\le r<2^L$, set $u=T^L(r)$ and $A=3^{j_L(r)}$. The affine transport identity is
\[
T^L(r+2^Lq)=u+Aq,
\]
and the odd-step count is constant on this residue class.
\begin{theorem}
Assume $A<2^L$. For every natural $q$, the seed $r+2^Lq$ is paradoxical exactly when
\[
0<r+2^Lq,\quad r\le u,\quad
q\le\left\lfloor\frac{u-r}{2^L-A}\right\rfloor.
\]
\end{theorem}
\begin{proof}
Non-descent is equivalent to $r+2^Lq\le u+Aq$, or $r+(2^L-A)q\le u$. Since the coefficient is positive, this is precisely the stated interval and $r\le u$. Positivity excludes the zero seed. In Lean, retaining $r\le u$ is essential because natural subtraction truncates at zero.
\end{proof}
To enumerate seeds at least three, impose also
$q\ge\max(0,\lceil(3-r)/2^L\rceil)$. Noncontracting residues contribute none. The unique decomposition $n=(n\bmod2^L)+2^L\lfloor n/2^L\rfloor$ proves coverage of all seeds at the selected length.

\section{Checked small case and experiment}
\begin{theorem}
For every $n>2$, the length-eight segment is paradoxical if and only if
\[
n\in\{7,9,18,19,25\}.
\]
\end{theorem}
\begin{proof}
A kernel-decided table checks all 256 residues. Every contracting residue with $u\ge r$ satisfies $u-r<256-A$, so its admissible quotient is zero. The possible residues are $0,1,2,7,9,18,19,25$; the first three are excluded by $n>2$. The five remaining trajectories directly satisfy the definition.
\end{proof}

The length-twenty census is a tested Python computation, not a Lean-extracted or kernel-certified enumeration. Only the displayed length-eight classification has been proved in Lean.

\section{Research role and reproducibility}
Rozier and Terracol prove that finiteness of paradoxical segments above seed two would imply Collatz~\cite{RT}. Their reduction is already represented in the nested source \path{rwst__lean-code/RT/CRozLemma32.lean}. Its local toolchain differs from the main project's; that nested headline theorem was source-inspected, not rebuilt or axiom-audited in this pass. It is not imported by the new module. Other nearby library results use cited computational assumptions, which must not be silently imported as proofs.

The new main module is \texttt{lean/Collatz/Paradoxical.lean}. Its principal declarations are

paradoxical\_residue\_iff\\
paradoxical\_eight\_iff
\end{quote}
These are included in the expanded 64-declaration audit, with only standard foundational axioms. No new axiom, \texttt{sorry}, or \texttt{native\_decide} is used. The table uses ordinary kernel-checked \texttt{decide}.

Build with \texttt{lake build Collatz.Paradoxical} from \texttt{lean/}. From the repository root, run {\small\texttt{python3 analysis/paradoxical\_cylinders.py}}; the JSON output records the exact finite scope. Brute-force residue enumeration costs exponentially many states. The prefix pruning extension below avoids many of those states, without establishing all-length termination. The missing task is an independently proved restriction on the contracting words that could support arbitrarily long paradoxical segments. Finite experimental absence does not supply that restriction.

\section{A proved prefix-pruning rule}
Represent a parity word by Boolean letters in orbit order. For a word $w$, let $|w|$ be its length, $j(w)$ its number of ones, and $d(w)$ its affine correction. The exact composition identity is
\[
d(uv)=3^{j(v)}d(u)+2^{|u|}d(v).
\]
The maximal suffix correction at fixed length $h$ and odd count $k$ is bounded by
\begin{equation}\label{eq:suffix}
d(v)\le2^{h-k}(3^k-2^k).
\end{equation}
This is the same extremal correction bound appearing in Rozier--Terracol~\cite{RT}, Theorem 2.2, translated from the remainder $d(v)/2^h$ to the integer correction. The new module proves it directly by induction, without importing that paper's formalization.

\begin{theorem}
Let a prefix $u$ have length $s$, odd count $a$, and correction $D$. Every suffix $v$ of length $h$ and odd count $k$ satisfies
\[
d(uv)\le U_k:=3^kD+2^{s+h-k}(3^k-2^k).
\]
Suppose a seed $n\ge m$ realizes $uv$ and $3^{a+k}<2^{s+h}$. If
\begin{equation}\label{eq:prune}
U_k<(2^{s+h}-3^{a+k})m,
\end{equation}
then its segment of length $s+h$ is not paradoxical.
\end{theorem}
\begin{proof}
The upper bound follows from composition and~\eqref{eq:suffix}. If the endpoint is at least $n$, the exact affine identity gives
\[
(2^{s+h}-3^{a+k})n\le d(uv)\le U_k.
\]
The positive coefficient and $n\ge m$ contradict~\eqref{eq:prune}.
\end{proof}
For a canonical prefix residue $r\bmod2^s$, the smallest seed at least three in the class is
\[
m=r+2^s\max\!\left(0,\left\lceil\frac{3-r}{2^s}\right\rceil\right).
\]
Check all $k=0,\ldots,h$. A noncontracting count contributes no paradoxical completion. If every contracting count passes the strict pruning test, the entire prefix subtree can be discarded. No monotonicity shortcut over the possible counts is assumed in the implementation.

The induction behind~\eqref{eq:suffix} first proves the division-free inequality
\[
2^{j(w)}(d(w)+2^{|w|})\le2^{|w|}3^{j(w)}.
\]
Then $j(w)\le|w|$ and cancellation of $2^{j(w)}>0$ give~\eqref{eq:suffix}. These steps and the exclusion theorem are checked in \texttt{Collatz.ParadoxicalPruning}.

\section{Search results and verification boundary}
The implementation \texttt{analysis/paradoxical\_pruned.py} follows residue lifts in a depth-first tree. Each node stores its depth, residue, endpoint, odd count, and correction. The affine identity is checked at every visited node. Surviving leaves use the exact quotient interval from Section 1, so there is no seed-height cutoff.

The six Python controls include exhaustive comparisons through length fourteen, all short suffix bounds through length eight, direct residue and endpoint checks, and a test that a work-limited run cannot report completion. Every emitted segment is independently replayed with the shortcut rule. The JSON file \texttt{analysis/paradoxical\_pruned\_results.json} preserves the status and discovered segments.

\subsection*{Formal and computational claims}
The added module proves \texttt{correction\_upper}, the completion bound, and the pruning implication. These mathematical statements are in Lean. The Python tree traversal and the reported larger-length counts are tested computations, not Lean-extracted code or kernel-verified search certificates. The existing all-seed length-eight classification remains separately kernel-proved. The selected 64-declaration audit includes the new bounds and reports only standard foundational axioms.

Build from \texttt{lean/} with
\begin{quote}\small\ttfamily
lake build Collatz.ParadoxicalPruning
\end{quote}
From the repository root, reproduce the experiment with
\begin{quote}\small\ttfamily
python3 analysis/paradoxical\_pruned.py
\end{quote}
The result makes fixed-length investigation substantially more practical, but does not yield a uniform cutoff on possible lengths. The length-65 work limit is an observed computational boundary, not a mathematical obstruction. A restriction uniform in length or circuit count is still needed to obtain global paradoxical finiteness and use the existing reduction to Collatz.
